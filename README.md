# Meu Campus — Aplicativo Acadêmico

Projeto acadêmico desenvolvido em **Flutter e Dart**, como parte das atividades da disciplina de Computação Móvel.

O aplicativo simula um ambiente de consulta a informações acadêmicas, permitindo visualizar dados de aulas, disciplinas e avisos.

## Funcionalidades

- Visualização de informações da próxima aula
- Consulta de informações de uma disciplina
- Exibição de avisos em uma janela modal
- Navegação entre telas
- Utilização de imagens e componentes visuais

## Conceitos trabalhados

- StatelessWidget e StatefulWidget
- Construção de interfaces com widgets
- Navegação com Navigator
- ModalBottomSheet
- Organização de layouts com Row e Column
- Utilização de imagens locais (assets)

## Tecnologias utilizadas

- Flutter
- Dart
- Material Design

**Finalidade:** projeto desenvolvido exclusivamente para fins acadêmicos, com foco no aprendizado dos fundamentos de desenvolvimento mobile.
